# 指南

## 项目结构

### 准备部分

#### `templates/`

存储构建页面需要的全部模板，可在此修改、添加样式。

#### `docs/`

存储构建页面需要的原始markdown文档。

#### `public/`

存储markdown文档所引用的文件。

### 产出部分

#### `output/`

构建后的产出文件。

#### `log/`

构建时所产生的日志。

## 步骤

### 0. 准备

安装版本至少为`3.10`的`python`。

### 1. 配置数据

在`config.json`中写入`name`和`output_url`键，分别对应"产出文件的标题"和"产出目录的URL"。

"产出目录的URL"需要指向产出目录，结尾需要`/`斜杠。比如说，创建一个`output/xxx.json`，那么URL`{output_url}xxx.json`需要指向这个文件。（如果你还未确定如何发布，可以先留空，完成后再填写）

### 2. 编写文档

编写的文档为markdown格式。

#### 文档元数据

文档的元数据需要写在文档的开头，yaml语法，格式类似：

```markdown
---
name: "介绍"
entrance: true
---
```

有以下元数据可填写

##### `name / title`

字符串，默认为文件名（不含`.md`后缀）

文档的名称，在目录和标题中使用。

优先`title`键

##### `entrance`

布尔值，默认为`false`

是否作为整个帮助文档的入口点。如果为true，则在产出目录中会固定有`Custom.xaml`文件，复制整个此文档。

只能有一个文档的`entrance`为true。

##### `visiable`

布尔值，默认为`true`

是否在目录中显示（`true`为显示）。此文档中的目录仍会显示。

#### 子目录

可以在`docs/`中创建目录，从而在目录中分级显示文档。

##### 子目录配置

可以在`子目录/config.json`中配置子目录。

有以下键值可填写。

###### `name`

字符串，默认为文件夹名

子目录的名称，在目录和标题中使用。

子目录的`name`不能与同级的文章/子目录的`name`相同。如果本文章是子目录索引页，则此项会被子目录的`name`占用。

###### `folded`

布尔值，默认为`false`

是否默认折叠。折叠后，若当前文章不在此子目录里，则不会显示此子目录的文章（而是在右侧显示下拉箭头）。

##### 子目录索引页

可以通过创建`子目录/index.md`从而设置子目录索引页。

在目录中点击子目录后，会直接定向到此页。在目录中，不会显示子目录索引页。

#### 排除文件夹

`docs`内文件名开头为`.`的文件/文件夹均不会被识别

#### 支持的语法

[支持的语法](jump!指南/支持的语法)

#### 页脚

可以通过调整`templates/sidebar/footer.xaml`来调整所有页面的页脚。

##### 支持的占位符

可以在页脚中写上特定的占位符，替换到特定的文本。

- `{ver}` 当前 PCLCustomHelpBuilder 的版本。

#### 默认主页

如无入口点文章，则`Custom.xaml`文件即为默认主页。

### 3.构建

安装依赖：`pip install -r requirements.txt`

运行：`main.py`

`output/`内即为产出文件。
