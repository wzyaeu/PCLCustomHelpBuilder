# 子目录

在文档目录中创建目录，从而使文档分级显示。

# 子目录配置文件

设置子目录在目录中的显示。位于子目录的`config.json`文件。

## 字段说明

## `name`

子目录的名称。此项会显示在目录中，如未填写则使用文件名作为子目录的名称。

> [tip]
> 子目录索引页元数据中的`name`字段会覆盖子目录配置文件的`name`字段。
>
> 最终以 子目录索引页元数据 > 子目录配置文件 > 子目录名称 顺序获取

## `folded`

是否折叠，默认为`false`。`folded`为`true`时，除非文档位于子目录内，否则子目录内部的内容将会折叠。

## `index`

子目录在目录中的排序，数字越小越靠前。默认为`0`。

> [tip]
> 子目录索引页元数据中的`index`字段会覆盖子目录配置文件的`index`字段。
>
> 最终以 子目录索引页元数据 > 子目录配置文件 > 默认值 顺序获取

# 子目录索引页

子目录的目录文档，位于与子目录位置同目录的名的位置，例如`/sub/`子目录的子目录索引页为`/sub.md`。
