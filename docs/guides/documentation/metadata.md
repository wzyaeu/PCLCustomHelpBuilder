# 文档元数据

设置文档在目录中的显示，位于文档开头。

> [tip]
> 元数据位于文档的开头。
> ```markdown
> ---
> title: ...
> entrance: true
> ---
> ```

# 字段说明

## `title`

文档的名称。此项会显示在目录中，如未填写则使用文件名作为文档的名称。

> [tip]
> `name`字段也具有相同的功能。优先解析`title`字段。

## `entrance`

文档是否作为整个帮助文档的入口点，默认为`false`。`entrance`为`true`时将会在产出目录复制文档页面到`Custom.xaml`中。

> [tip]
> 没有入口点时，也会创建`Custom.xaml`。

> [warn]
> 只能有一个文档的`entrance`为`true`。

## `visiable`

文档是否在目录中显示，默认为`true`。`visiable`为`false`时仍会构建文档的页面。

## `index`

文档在目录中的排序，数字越小越靠前。默认为`0`。

## `tags`

文档的标签，默认为`[]`。当有文档含有标签时，会在目录下方创建标签列表，并标记出拥有此标签的文档数。
