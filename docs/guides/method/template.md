# 文档模板

通过文档模板创建一系列格式相同的段落

## 创建文档模板

文档模板位于文档模板目录`文档目录/.template`中。

### 文档模板名称

文档模板根据在**文档模板目录**的位置确定文档模板名称。

如`文档目录/.template/test.md`的名称为`test`。

`文档目录/.template/github/repo.md`的名称为`github/repo`。

## 文档模板语法

文档模板语法相较于普通文档，额外添加了模板语法。

#### 模板语法

在文档模板语法中可使用`[](doctemplate!key)` `[](doctemplate!key!default)`格式创建模板语法。

每个模板语法相当于一个占位符，会在使用文档模板时被替换。

#### 于代码块中创建模板语法

在文档模板的代码块中可使用`{{doctemplate!key}}` `{{doctemplate!key!default}}`格式创建模板语法。

与普通模板语法一样，会在使用文档模板时被替换。
