# 文档目录外链

在文档目录链接内容。

文档目录外链需要在文档中创建以`.docjump.json`后缀的文件。

> 关于文件后缀，参阅[可变后缀](/指南/资料/可变后缀)

## 文档目录外链文件字段

### `name` 名称

文档目录外链的名称。默认为文件名。

### `type` 外链类型

文档目录外链的外链类型，可选`doc`、`web`。

- `doc`：跳转至项目的其他文档中。
- `web`：跳转至网址链接中。

也可以是 PCL 所支持的自定义事件类型，如`type: "弹出窗口"`。

### `data` 外链内容

根据外链类型来确定外链内容。

- `doc`：跳转至项目的其他文档中的位置，如`data: "指南/资料/可变后缀"`。
- `web`：跳转至网址链接中，如`data: "https://github.com/wzyaeu/PCLCustomHelpBuilder"`。

若外链类型是 PCL 的自定义事件类型，则输入事件数据，如`data: "标题|内容"`。

### `index` 序列

与文档元数据的`index`键一样，关于文档元数据，参见[元数据](/指南/入门/元数据)。
