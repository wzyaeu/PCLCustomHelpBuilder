# 引用文档模板

使用类似：
````markdown
```template
{template_path}
{parameter1}={input1}
{parameter2}={input2}
...
```
````
的格式即可引用文档模板。

````markdown
```template
test
```
```template
test
p1=参数1
```
````
```template
test
```
```template
test
p1=参数1
```

````markdown
```template
github/repo
userid=74000668
repo=Meloong-Git/PCL
````
